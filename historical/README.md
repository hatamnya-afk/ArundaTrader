# Historical / Archive Material

This directory is the canonical navigation point for historical material when files are physically grouped here.

Historical material is retained for provenance and recovery context, not as current project truth.

## Rules
- Never delete the corresponding Local material as part of GitHub organization.
- Do not treat backups, quarantine outputs, old repair artifacts, or obsolete investigations as current contracts.
- Do not restore historical code into the active runtime without explicit Management authorization.
- Closed/verified checkpoints remain historical truth unless a direct, provable regression is established.

The known Local backup/quarantine/archive classes are excluded from the GitHub synchronization snapshot according to `LOCAL_SYNC_MANIFEST.json`.
